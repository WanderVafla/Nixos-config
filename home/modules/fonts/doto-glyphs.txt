# "= <char> <Latin>" copies a Doto glyph that has the same shape.
# "= <char> <top>" draws a grid whose first row sits at y = <top>; every next row is 100 lower.
# Rows: capitals 650..50, lowercase 450..50, descenders down to -150, capital accents at 750.
# "#" is a dot, "." an empty cell. Lines that start with "# " are comments.
